CD3⁺ yield prediction

Minimum Viable Product

Early-stage prototype — shared for feedback and collaborative data collection; not a certified medical device. Predicts the T-cell yield of a leukapheresis in ×10⁶ CD3⁺ cells per kg body weight.

Note: Decision support only — not a substitute for clinical judgement. Please do not enter any patient-identifying data; use a pseudonym / sequential number for the case ID. The model is deliberately conservative (prediction below the actual value in ~90% of cases).

Model parameters (fixed — for information only)
Statistically estimated (solver, n = 253) — not modifiable: F50 = 7731 /µL · b₁ = 0.9318 · b₂ = 1.1035 · log α₀ = −2.9572 · αlow = 0.7482 (<405/µL) · αmedium = 0.7731 (405–780/µL) · αhigh = 0.6250 (>780/µL).
Calculation: CELLS_eff = CELLS/(1+CELLS/F50) · u = PV/GBV · Basis = α₀·CELLS_eff^b₁·u^b₂ · Prediction = α·Basis · GBV per Nadler (1962).
Automatic data submission (optional, research team)
By default data do not leave the browser — submission is via CSV export. An endpoint URL sends recorded cases additionally as JSON (HTTP POST); it must be operated GDPR-compliant (encrypted, access-controlled, no patient-identifying data).
Model M10′ · quality n = 253: r = 0.849; MAPE ≈ 30%; prediction < actual ≈ 89% per group. High group (CD3⁺ > 780/µL) most uncertain — validate prospectively before broad use. A collaboration of AKAD University and LMU Klinikum München.
